# Backend Doctor 1.1.0

Backend Doctor now opens an interactive console when scanning in a supported
terminal. Browse grouped issues, inspect source and recommendations, and copy
repair tasks for your AI assistant.

## New

- Actual scan-stage progress and a keyboard-operated result menu.
- Issue groups by category, rule and effective severity, with navigation through
  every occurrence and scrollable source excerpts, explanations and fixes.
- Enter-to-copy repair tasks for a selected issue group; a separate action copies
  the entire report. Tasks include affected locations, documentation, coverage and
  a verification command. Clipboard failures expose a manual-copy view.
- Links to shipped local documentation and the corresponding GitHub pages.
- An offline findings score with an explicit formula and coverage guard. Partial
  scans, skipped checks and zero analyzed files show why a score is unavailable.
- GitHub Actions setup from the result menu, with destination confirmation and
  protection for existing workflows.
- `--interactive` and `--no-interactive` scan flags. Piped output, CI, JSON and
  JSONL retain the existing reporters. `NO_COLOR` is respected.

## Fixes since 1.0.1

- Include re-export edges and TypeScript path aliases in import-graph analysis.
- Report syntax/read failures and visibly skip unsafe unused-code conclusions
  when the import graph is incomplete.
- Show analyzed coverage and skipped checks clearly in pretty reports, including
  scans with no supported TypeScript files.
- Support modern Prisma 6.14 queries through public extensions while preserving
  native event subscriptions, subclass behavior and transaction semantics.
- Keep the published defineConfig declaration self-contained; verify valid and
  invalid configuration types against the exact packed file set.

## Compatibility and verification

Node.js 20 or newer is supported. CLI exit codes, JSON `schemaVersion`, public
exports and configuration names are unchanged. The Prisma 7 standard generated
client loader remains unsupported; see the README compatibility boundary.

The console copies context locally; it does not launch an AI assistant, send code
to a service or apply source fixes. There is no separate product website yet.

Verified with 818 automated tests, two real Prisma compatibility tests,
typechecking, linting, installed-package
Node 20.20.2 terminal smoke tests and live WebStorm review. Native clipboard smoke
was performed on macOS; Linux/Windows clipboard paths have adapter tests.

## Try it

```sh
npx backend-doctor-cli@1.1.0 scan
```

Use arrows to navigate, Enter to copy, `d` for details, `s` for coverage and `q` to
exit. For automation, use `--format json`, `--format jsonl` or `--no-interactive`.
